Overview
This is the AP1 repository subdirectory for the C.A.L.S. system. It verifies standard input/output operations, C++ stream control flow, and basic arithmetic logic. The repository includes both the C++ source code and a precompiled binary for immediate testing.

Features
User personalisation: Captures the full user name string for personalised welcome and exit messages.
Input validation: Traps invalid inputs (e.g. string instead of int) using input stream resetting and buffer clearing.
Arithmetic operations: Calculates addition, multiplication, division, and modulo values for two integers.
Edge-case handling: Prevents crashes by checking for division by zero before running division or modulo logic.
